# ドット・クエスト 〜ちいさな勇者とドラゴン〜

ブラウザで遊べるRPG。スマホ対応。

Play: https://rodorin-lab.github.io/dot-quest-rpg/

## SRPG prototype (independent training battle)

タイトルの **SRPGおためし** で、10×6マスの訓練戦闘を開始します。
冒険・セーブデータ・通常戦闘から独立し、何度でも再挑戦できます。

- 青いマスをタップ／クリックして移動（1ターンに1回、最大3マス）。
- 隣接した赤枠の敵を選ぶと攻撃（射程1、移動前の攻撃も可能）。
- 勇者自身、または右下の「待機」で敵ターンへ。
- 十字キー／スマホの十字ボタンでカーソル移動、A / Z / Enterで決定。
- B / X / Escでタイトルへ。勝敗画面のA／再挑戦ボタンでリセット。
- 全敵撃破で勝利、勇者のHPが0で敗北。敵は障害物と占有マスを避けて接近します。

`js/tactics.js` はDOM・描画・音声に依存しない戦闘ルールです。
ユニットの `move`, `range`, `atk`, `def`, `sprite` はデータで指定できます。
今後のメカ装備・移動タイプ等の拡張はここへ、表示と入力の連携は
`index.html` の独立したSRPG訓練セクションへ追加できます。
現試作は固定ステータス、1主人公、2敵、単一マップ、決定論的ダメージです。
射程はマンハッタン距離で、遮蔽物による射線判定はまだありません。

ローカル起動（リポジトリのルートで実行）:

```sh
python -m http.server 8000
# http://localhost:8000 を開く
node --test tests/tactics.test.cjs
```
